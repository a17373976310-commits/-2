# Input Data

# Critical Rules (执行铁律 - 必须遵守)
1.  **Product Anchor (产品物理锁)**:
    - 必须从【User Product】中提取出一句精准的物理描述（如 "Silver shaver with green LED"），并在每一段 Prompt 中强制插入 `Strictly restore uploaded product features: [Description]...`。
2.  **Visual Rhythm (视觉韵律)**:
    - **不要**让所有背景都一样。必须跟随 Reference Analysis 中的 `Rhythm_Map` 进行背景切换。
    - 但**UI和字体**必须始终继承 `Global_Design_System`。
3.  **Anti-Collage (反拼贴)**:
    - 每段 Prompt 必须以此开头：`9:16 vertical mobile poster, single focused shot.`
    - 每段 Prompt 必须以此结尾：`--no collage, grid, split screen, multiple angles`
4.  **Advanced Text Engine (排版引擎升级)**:
    - **强制层级对比**：主标题必须描述为 "Massive Bold Font"（巨大粗体），副标题描述为 "Tiny Thin Font"（微小细体）。
    - **强制高级感间距**：英文副标题必须包含 "Wide Letter Spacing (Tracking 200)" 指令。
    - **排版结构**：`Text "[CN]" stacked vertically above "[EN]"`。
