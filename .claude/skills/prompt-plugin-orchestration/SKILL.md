# 提示词-插件编排框架

## 核心角色转变
```
以前（纯对话）：提示词 = 创作者（直接干活）
现在（带插件）：提示词 = 产品经理 + 翻译官 + 调度器
                 ↓
         听懂需求 → 翻译成JSON → 派发给插件 → 验收润色 → 交付
```

---

## 三层交互模式

### 🔄 Layer 1: 翻译层 (The Translator)
**场景**：自然语言 ↔ 机器语言

**作用**：
- **清洗意图**：用户说模糊的话，提示词翻译成精确需求
- **格式强制**：把人话拆解成插件需要的 JSON/SQL/代码

**模板**：
```
# 意图提取
分析用户输入: "{{user_input}}"
提取以下字段:
- 核心动作: (动词)
- 目标对象: (名词)
- 约束条件: (形容词/限定词)

# 参数化输出
严格输出以下JSON格式（错一个标点插件报错）:
{
  "action": "...",
  "target": "...",
  "constraints": {...}
}
```

**示例**：
```
用户: "明天去北京的天气"
↓ 翻译层
{ "city": "Beijing", "date": "2026-01-15" }
↓ 调用天气插件
```

---

### 📚 Layer 2: 增强层 (The Context Injector)
**场景**：知识库/RAG/联网搜索

**作用**：
- **前置判断**：模型知识够不够？需不需要查外部？
- **后置融合**：把插件返回的冷数据，融入对话流，用专家口吻讲出来

**模板**：
```
# 前置处理
检查是否需要外部知识:
- IF 涉及实时数据（股价/天气/新闻）→ 调用联网插件
- IF 涉及专业领域 → 调用知识库插件
- ELSE → 使用内置知识

# 后置融合
收到插件数据后:
1. 提取关键信息（不是全部复制）
2. 用自然语言重述
3. 与用户原始问题串联
4. 禁止直接甩链接/原始数据
```

---

### ⚙️ Layer 3: 编排层 (The Orchestrator)
**场景**：多阶段工作流 / 链式调用

**作用**：
- **状态保持**：A插件输出 → 提示词接住 → 无损传递给B插件
- **路由分发**：IF/ELSE条件判断，动态选择下游插件
- **错误自愈**：插件失败时尝试换策略重试

**工作流模板**：
```
┌──────────────┐
│   Stage 1    │  感知/分析
│   识别输入    │  → 输出: 特征JSON
└──────┬───────┘
       ↓
┌──────────────┐
│   Router     │  条件判断
│   IF 大件    │  → 调用: 落地展台模组
│   ELSE       │  → 调用: 悬浮模组
└──────┬───────┘
       ↓
┌──────────────┐
│   Stage 2    │  执行/生成
│   绘图插件    │  → 输出: 最终图片
└──────┬───────┘
       ↓
┌──────────────┐
│   Validator  │  质量检查
│   IF 失败    │  → 触发: 自愈重试
│   ELSE       │  → 返回: 最终结果
└──────────────┘
```

**路由判断模板**：
```
# 路由逻辑
根据 Stage 1 输出的特征:
{
  "product_type": "{{type}}",
  "size": "{{size}}",
  "material": "{{material}}"
}

执行路由:
- IF size == "large" AND material == "hard":
    → 调用 "floor_display_module"
- ELIF size == "small" AND material == "soft":
    → 调用 "floating_module"
- ELSE:
    → 调用 "default_module"
```

**错误自愈模板**：
```
# 自愈机制
IF 插件返回错误 OR 结果不符合预期:
  1. 记录错误类型
  2. 根据错误类型选择修正策略:
     - 格式错误 → 重新强调输出格式
     - 内容错误 → 增加负向约束
     - 超时错误 → 简化请求重试
  3. 最多重试 3 次
  4. 仍失败 → 返回降级方案
```

## 实战检查清单

设计插件交互时问自己：
- [ ] 翻译层是否精准？（JSON格式会不会出错）
- [ ] 增强层是否融合？（不是甩数据而是讲人话）
- [ ] 编排层状态是否连续？（A→B信息有没有丢失）
- [ ] 路由判断是否完备？（所有情况都覆盖了吗）
- [ ] 自愈机制是否存在？（失败了怎么办）
